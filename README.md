# Rodin for Unreal Canvas

Turn a reference image into a 3D mesh with your Hyper3D account, then use the GLB on your canvas. You can also rig a mesh or split a Rodin model into parts.

## Install in Unreal Canvas

This preview targets Unreal Canvas 0.21.0. You'll need a Hyper3D account and a network connection. On first use, Canvas downloads the Python dependencies from PyPI into its worker environment (Python 3.10 or later).

1. Open **Settings → Extensions**. If your team gave you a catalog folder or URL, open **Sources**, paste it, and select **Add**.
2. Under **Available → Plugins**, find **Rodin for Unreal Canvas** and select **Install**.
3. Under **Installed**, select **Allow** if prompted.

If you only have the Git repository URL, ask your team for the preview catalog. Canvas requires a release tag for Git installation.

## Generate your first mesh

1. Add one reference image to the canvas, or use the image output from a previous generation.
2. Choose **Mesh**, select **Rodin MCP Image to 3D**, and add the image to **Inputs**.
3. Open the model parameters to choose **Tier** and **Mesh mode**, then select **Generate**.
4. On your first run, look for the verification code at the top of Canvas. After three seconds, the Hyper3D authorization page opens in your browser. Check that the codes match and approve. Canvas continues the same job and returns a GLB when generation finishes.

Generation uses your Hyper3D account and is billable. If you select **Stop** after submission, Canvas stops waiting, but the cloud job may still finish.

## Rig a mesh or split it into parts

- **Auto-Rig** accepts a mesh from Rodin or a local mesh file. In **Auto-Rig**, select **Rodin MCP Auto-Rig**, connect the mesh, and choose a **Skeleton** template. The result is a rigged GLB.
- **Rodin BANG** accepts a mesh generated by this extension on this machine. Connect the original GLB to the **Rodin BANG** graph card and adjust **Strength**. It sets a target for the number of parts. The result is a GLB containing the parts.

## Manage your sign-in

To sign in before generating, run the **Rodin Sign In** graph card. **Rodin Account Status** shows whether a session is saved on this computer. To sign out locally, run `python scripts/rodin_auth.py logout` from the installed plugin's directory.

Windows protects the session with your Windows account. On macOS, install Apple's Command Line Tools and allow Keychain access when prompted. On Linux, install `secret-tool` (`libsecret-tools` on Ubuntu) and unlock your desktop keyring.
